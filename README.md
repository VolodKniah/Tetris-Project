# Tetris
### A classis Tetris implementation using Python and Pygame.
## Installation:
1) Make sure you have Python 3.x and Pygame installed.
2) Run game.py.
## Controls:
#### Left / Right Arrows: Move piece horizontally.
#### Up Arrow: Rotate piece by 90 degrees.
#### Down Arrow: Move piece one space down.
#### S key: Hard drop (immediately move the piece to the bottom).
#### E key: Swap the piece with held piece.
#### R key: Restart the game (keeping the high score).
#### ESCAPE key: Exit the game.
